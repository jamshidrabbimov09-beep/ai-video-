# 3-qism: ElevenLabs uchun tayyor matn

Eleven v4, oldingi qismlardagi OVOZ va sozlamalar. Har blokni alohida yozing: A.mp3 ... F.mp3.
Teg o'qib yuborilsa, o'rniga `...` qo'ying. Matn Yazdiy va Manz kitoblari bo'yicha tekshirilgan: so'zlarni o'zgartirmang.
Talaffuz: Suyurg'atmish = su-yur-g'at-mish; Saroymulkxonim = sa-roy-mulk-xo-nim; Ko'ragon = ko'-ra-gon.

## A
```
U ulkan saltanat qurdi. [short pause] Lekin umrining oxirigacha o'zini xon deb atamadi. [short pause] Nega? Chunki bunga uning haqqi yo'q edi. [long pause] Bu Amir Temur hokimiyatni qanday qo'lga olgani haqidagi qissa.
```

## B

## C
```

```

## D
